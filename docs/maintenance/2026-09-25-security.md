# Security maintenance — 2026-09-25

Upgraded Electron to 44.4.5, better-sqlite3 to 13.0.3 and node-pty to 1.1.0,
with current compatible JavaScript packages and patched tar, temporary-file,
image-size and ZIP extraction dependencies. The full npm audit has no findings.
Small patch-package adapters preserve archive/image behavior while using the
patched implementations; malformed-input and ordinary-input controls pass.

The packaged application previously omitted its renderer and external native
modules. Forge now includes the Vite output and production dependencies, unpacks
native SQLite and PTY artifacts, and signs local macOS packages ad hoc. This is
local build signing, not Developer ID notarization. The maintained Electron
rebuild command uses the installed runtime's headers and verifies actual module
loading; it does not depend on an ABI lookup table that lacks Electron 44.

Verification: 238 unit tests, TypeScript, dependency boundary tests, DMG/ZIP
creation, packaged-file assertions, and strict deep macOS signature verification.
The actual packaged runtime passes startup, renderer, SQLite persistence across
restart, PTY I/O and pop-out lifecycle tests. The smoke test explicitly isolates
both application HOME and Chromium user-data; a fresh run verified the real
profile's 53 files remained unchanged. An earlier diagnostic omitted that
Chromium override and touched the app's real profile/cache; no session database
or provider credential was used by the diagnostic.

Repeat: npm ci; npm run rebuild:electron; npm test; npm run typecheck;
npm run test:dependency-security; npm run build; npm run test:artifact;
npm run test:packaged; npm audit. Back up the installed application and session
database before replacing a working installation. Retain the prior application
for rollback; returning to it reintroduces its old runtime advisories.
